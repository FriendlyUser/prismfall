Privacy Policy – Prismfall

Last updated: November 21, 2026

Prismfall ("the game") is a bullet-heaven game for Android and the web, developed by David Li (GitHub: FriendlyUser). The game does not collect, store or share any personal or device data.

What the game does not do

  • No account, sign-in or registration.
  • No analytics, advertising or tracking SDKs, and no in-app purchases.
  • No network access: the Android app requests no permissions, including no internet permission.

What stays on your device

The game saves your progress (shards, shop upgrades, unlocked sectors and best results) and your settings (graphics quality, volume, screen shake and touch controls) in a small file inside the app's private storage. This file never leaves your device and is deleted when you uninstall the game. In the web version, the same data is kept in your browser's local storage for this site.

Web version

The web version is a static page served by GitHub Pages. GitHub may keep standard server logs (such as IP addresses) as described in the GitHub Privacy Statement; the game itself sends nothing.

Children

The game is not directed at children under 13.

If this policy changes, the new version will be published at this address.
